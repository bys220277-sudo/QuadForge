# QuadForge — автоматическая ретопология

Аддон для Blender 4.2+ (Windows x64): превращает любой меш в чистую сетку из квадов.

- Своё многопоточное ядро на C++17: изотропный ремешинг, кросс-поле 4-RoSy, целочисленная параметризация, извлечение квадов, ремонт и релаксация с проекцией на исходник.
- Направляющие рёбра, анализ качества сетки.
- Если ядро недоступно, используется встроенный Quadriflow.

## Установка

Скачайте [quadforge-1.0.2.zip](download/quadforge-1.0.2.zip) и установите в Blender: *Edit → Preferences → Add-ons → Install from Disk…*. Панель: 3D Viewport → **N** → вкладка **QuadForge**.

## Сборка ядра

Готовая библиотека лежит в `lib/windows-x64/`. Исходники ядра в `native/`, собрать заново: `python tools/build_native.py` (нужны CMake и компилятор C++17).
